How to reduce an image file size

Choose an image, select a quality setting, and compare the resulting file size with the original. JPEG and WebP are useful for photographs; PNG is often better for graphics that need transparency. Check the downloaded image before using it, because lower file sizes can mean lower visual quality.

How to resize an image without stretching it

Keep the aspect-ratio option enabled when changing width or height. This preserves the image's proportions. For a profile picture or banner, check the target website's recommended dimensions before resizing.

What a word count includes

Word counters typically treat groups of characters separated by whitespace as words. Different writing apps can count punctuation, hyphenated terms, and languages differently, so use the result as a helpful estimate rather than an official submission count.

Use passwords and QR codes carefully

Use a unique password for every account and store it in a reputable password manager. Before sharing a QR code, scan it yourself and verify the destination. Never put confidential information into a QR code intended for public distribution.
