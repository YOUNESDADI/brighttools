# BrightTools — starter website

A responsive static website with six browser-based tools:
- Image Compressor
- Image Resizer
- Word Counter
- Case Converter
- Password Generator
- QR Code Generator

## Run locally
Open `index.html` in a modern browser. The QR generator uses a QRCode.js CDN library, so it needs an internet connection. Other tools work locally in the browser.

## Before publishing
1. Pick a final brand name and check that it is available.
2. Replace `hello@example.com` with an address you control.
3. Add a complete, accurate privacy policy and terms page before adding analytics or ads.
4. Test on mobile and desktop browsers.
5. Consider security, accessibility, file-size limits, and privacy before public launch.
6. The website currently has no ad code, analytics, backend, or user accounts.
